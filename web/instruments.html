SIDKid Instrument maker
Song player

An instrument is how a note sounds: a volume envelope, plus up to three small programs the player runs 50 times a second while the note plays. A wave program picks the waveform and pitch, a pulse program shapes the pulse width, and a filter program moves the filter. Pick a program on the left to use it in the instrument below; instruments can share them.
