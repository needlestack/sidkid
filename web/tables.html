SIDKid Table maker
Song player

Tables are tiny programs the SID player runs 50 times a second while a note plays. Each step changes the sound a little: a wave program picks the waveform and pitch, a pulse program shapes the pulse width, and a filter program moves the filter. Instruments, which come next, point at these programs.
